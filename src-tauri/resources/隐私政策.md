# 隐私政策

**即记(Jot)**（以下简称"本软件"）由 **apidata.cc**（以下简称"我们"或"开发方"）开发并作为**开源软件**提供。本软件按"现状"供您使用。

我们非常重视您的个人信息保护，并严格遵守《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》等法律法规。本隐私政策旨在向您说明，当您使用本软件时，您的数据如何被处理、存储和对外流动，以及您所享有的权利。

**开源透明**：本软件为开源软件（MIT 许可证），源代码在 [GitHub](https://github.com/fatefl/jot) 公开。您可随时查阅源代码以核验本政策所述的数据处理行为。本政策适用于开发方通过官方渠道发布的版本；如您自行编译源码或使用第三方修改版本，其数据处理行为可能与本政策描述不同，请以相应版本的实际情况为准。

**请您在使用本软件前仔细阅读并理解本政策。** 如您选择使用本软件，即表示您已充分知晓并同意本政策的全部内容。

本隐私政策中的术语，除另有定义外，与本软件的[《用户协议》](用户协议.md)中的术语具有相同含义。本政策仅适用于本软件本身，不适用于我们的官方网站、支持页面或其他相关网站。


## 一、数据处理的总体原则

本软件是一款**本地优先（local-first）**的笔记应用：您的笔记以 Markdown 文件形式存储在**您自行选择的本地目录**中，没有数据库、没有专有格式，也不经过任何中间服务器。

**默认情况下，本软件不会向开发方传输任何数据，开发方无法访问您的笔记内容。** 您在本地产生的数据（笔记正文、标签、元数据、反向链接索引、编辑器设置等）**仅存储于您的本地设备**，由您完全掌控。

在少数场景中，数据可能**由您主动触发**地流向第三方（详见对应章节），除此之外不存在其他数据出口：

| 数据出口 | 触发方式 | 涉及的数据 | 详见 |
|---|---|---|---|
| Git 远程仓库 | 您配置远程并主动推送/拉取 | 笔记仓库的全部内容 | 第二章 |
| AI 助手（MCP） | 您主动接入 MCP 客户端 | 被读取/写入的笔记内容 | 第三章 |
| 外部网络资源 | 笔记中引用远程图片/链接 | 笔记内的网络资源请求 | 第五章 |

此外，本软件**不提供任何账户体系**，您无需注册即可使用全部功能；本软件**不投放广告，不进行任何形式的用户画像或精准营销**。


## 二、Git 版本管理工具及远程仓库

- **本地 Git 客户端（可选安装）**：当您使用版本管理、同步或备份功能时，本软件会调用您本地安装的 Git 客户端。
- **远程 Git 仓库（如 GitHub、GitLab、Gitee 等）**：当您主动执行推送、拉取、克隆等操作时，您的笔记数据会通过本地 Git 客户端发送至您所配置的远程仓库服务商。

**重要说明**：
- 上述 Git 相关操作**完全由您手动配置并主动触发**，本软件不会自动向任何远程仓库上传数据。
- 您传输到远程仓库的数据内容、提交记录等，受您所选择的第三方服务商（如 Gitee、GitHub 等）的隐私政策与服务协议约束。
- 同步发生冲突时，本软件会在本地保存远端版本的"冲突副本"（文件名为 `原名 (conflict 日期 时间).md`），该副本**仅存储于您的本地设备**。

**使用建议**：远程仓库服务由您主动决定是否配置。请您在使用前，仔细阅读并同意相应第三方服务商的隐私条款与服务协议。


## 三、AI 助手（MCP 服务）

本软件内置 MCP（Model Context Protocol）侧车服务，允许支持 MCP 的 AI 助手**读取、搜索、编辑您笔记目录中的 Markdown 文件**。

**重要说明**：
- **MCP 服务运行在您的本地设备上**，本软件自身不会上传或记录这些交互内容。
- 当您将 MCP 服务接入云端 AI 服务商（如 Claude、ChatGPT 等）时，**AI 助手为完成您的指令，会将相关的笔记内容发送至该服务商**。该传输由您主动发起，处理方式受相应 AI 服务商的隐私政策约束。
- 您在接入 MCP 前，请务必确认所使用 AI 服务商的数据处理政策，并只向可信的 AI 助手授予笔记目录访问权限。
- 本软件不对任何第三方 AI 服务商的数据处理行为承担法律责任。


## 四、文档转换工具（Pandoc）

- **[Pandoc](https://pandoc.org/)（可选安装）**：当您使用导入/导出 docx、epub、LaTeX 等格式时，本软件会启动本地 Pandoc，并将当前文件内容转换后传递给 Pandoc 进行处理。该处理**完全在本地完成**，不涉及网络传输。


## 五、外部站点与网络资源

- 如果您在笔记中插入来自网络的图片、视频、iframe 等资源，或者打开包含此类远程资源的文档，本软件会自动从相应网站加载这些内容，该行为可能导致这些网站获取您的访问信息（如 IP 地址、浏览器标识等）。
- 若您点击笔记内的第三方链接并跳转至外部网站，相关数据收集由该网站负责。

我们建议您审慎访问外部链接，并查阅目标网站的隐私政策。我们对任何外部网站的内容和隐私保护措施不承担法律责任。


## 六、凭据管理说明

在需要身份验证的功能（如 Git 远程仓库操作）中，您提供的凭据（用户名、密码、Token 等）经您本机的安全凭据存储服务**加密保存于您的本地设备**，我们不会获取、存储或传输您的原始凭据，也不会将其上传至任何服务器。

具体实现方式因操作系统而异：

### 1. macOS 平台
- 本软件可能使用 **macOS 钥匙串（Keychain）** 安全存储您为特定服务（如 Git 仓库）设置的访问令牌或密码。
- 您可通过"钥匙串访问"应用查看和管理本软件存储的凭据条目。

### 2. Windows 平台
- 本软件可能使用 **Windows 凭据管理器（Credential Manager）** 存储相关服务的登录凭据。
- 您可在"控制面板" → "用户账户" → "凭据管理器"中查看或删除本软件保存的凭据。

### 3. Linux 平台
- 本软件可能使用 **Secret Service API**（如 GNOME Keyring、KDE Wallet 等）或直接调用 Git 内置的凭据缓存机制（如 `git-credential-store`、`git-credential-cache` 等）。
- 具体的存储方式取决于您的桌面环境配置，本软件本身不提供独立的凭据存储实现。

### 通用说明
- **凭据用途**：上述凭据仅用于您主动发起的远程服务访问（例如向 GitHub、Gitee 等推送笔记仓库），本软件不会用于任何其他目的。
- **读取时机**：凭据仅在您主动执行相关操作（如推送/拉取）时被读取使用。
- **用户控制权**：您可随时通过操作系统工具或 Git 命令行清除已保存的凭据，本软件不会在系统凭据存储之外保留任何副本。
- **安全提示**：我们建议您为不同服务设置独立的强密码或使用令牌（Token），并定期更换，以降低凭据泄露风险。


## 七、您的个人信息权利

基于上述"本地优先"原则，**本软件不收集、不持有您的个人信息**，您的数据完全由您自行掌控。尽管如此，根据中国法律法规，您对您的个人信息享有以下权利：

- **知情权与决定权**：您有权了解您的数据如何被处理（本政策即为说明），并有权决定是否使用相关功能；
- **访问、更正与删除权**：由于您的数据存储于本地，您可以随时直接查看、修改或删除；
- **撤回同意权**：您可以随时停止使用相关功能或退出第三方服务，以撤回相应授权；
- **注销账户**：本软件不提供账户体系，因此不存在需要注销的账户。

如果您通过反馈渠道向我们提供了个人信息（见第十一章），您同样有权要求我们删除该等信息，我们将在**15个工作日内**予以处理。


## 八、信息共享与披露

由于本软件**不向开发方传输、也不持有您的个人信息**，我们不存在向第三方"共享"或"出售"您个人信息的商业行为。您的数据仅在以下情形下可能被第三方获取：

1. 您主动触发并授权（如推送至您配置的 Git 远程仓库、接入 AI 助手）；
2. 应法律法规、司法或行政命令的要求（如有），我们依法配合并提供必要信息。

对第三方获取数据后的处理行为，由相应第三方依据其自身隐私政策负责。


## 九、安全保护措施

本软件采用本地优先的设计，最大程度减少数据暴露面：

- **数据本地化**：笔记、凭据等敏感数据均存储于您的本地设备，不经过中间服务器。
- **原子写入**：所有文件写入均采用"临时文件 + 重命名"方式，避免写入中断导致的数据损坏。
- **系统凭据保护**：远程仓库凭据经操作系统级安全存储（Keychain / 凭据管理器 / Secret Service）加密保存。
- **开源可审计**：源代码公开，任何安全研究者均可审查实现，发现问题可及时向我们反馈。

**请您理解**：本地数据的安全同样取决于您设备的系统安全状况，请妥善保管您的设备与系统账户。如本软件自身被发现存在安全漏洞，我们将通过官方渠道（GitHub、官网）及时发布修复版本并公告。


## 十、未成年人保护

本软件不面向**14周岁以下**的未成年人，且不主动收集个人信息，正常情况下不存在收集未成年人个人信息的情形。如您是家长或监护人，并发现您的孩子在使用本软件过程中向我们提供了个人信息，请及时联系我们处理。
